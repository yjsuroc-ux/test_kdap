# 문서 처리 기한 관리 도구 (MVP)

온나라 접수 목록 엑셀과 본문 HWP를 올리면 회신·전파 여부와 기한을 규칙으로 찾아 담당자별 업무로 등록합니다. 오늘/주간/월간, 내 업무/부서 전체로 볼 수 있고, 단계별 기한과 템플릿을 관리합니다.

## 1. 실행 (서버 PC)

```bat
run.bat
```

또는 직접 실행:

```bat
python app.py
```

- 실행하면 화면에 접속 주소가 나옵니다. 이 PC에서는 `http://localhost:8000`, 다른 PC에서는 `http://서버IP:8000`으로 접속합니다.
- 포트 변경: `set PORT=9000` 후 실행
- 다른 PC에서 접속이 안 되면 Windows 방화벽에서 해당 포트(8000) 인바운드 허용이 필요합니다(관리자에게 요청).
- 종료: 실행 창에서 `Ctrl+C`

## 2. 설치 (최초 1회)

1. Python 3.10 이상 설치 (설치 시 "Add python.exe to PATH" 체크)
2. 패키지 설치
   ```bat
   python -m pip install -r requirements.txt
   ```

### 내부망(인터넷 없음) 서버에 설치할 때

인터넷이 되는 PC(서버와 같은 Python 버전, 64비트 Windows)에서 패키지 파일을 받아 반입합니다.

```bat
python -m pip download -r requirements.txt -d wheels
```

`wheels` 폴더와 이 프로그램 폴더 전체를 서버로 옮긴 뒤:

```bat
python -m pip install --no-index --find-links wheels -r requirements.txt
```

화면은 외부 CDN을 쓰지 않으므로 추가로 받을 것은 없습니다.

(`requirements.txt`의 `psycopg`는 클라우드 배포용입니다. 내부망 서버에서는 설치되지 않아도 동작합니다.)

## 2-1. Vercel 시연 배포 (가상 샘플 전용)

> ⚠ **시연·시험용입니다.** Vercel은 인터넷 공개 서비스이고 이 도구에는 로그인이 없어, 주소를 아는 누구나 조회·수정·초기화할 수 있습니다. **실제 온나라 문서(비공개 문서 포함)는 올리지 마세요.** 실사용은 내부망 서버(`run.bat`)로 합니다. 배포 화면 위쪽에도 이 안내가 표시됩니다.

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인 → **Add New → Project** → 이 저장소 선택 → **Deploy**
   - 설정은 `vercel.json`에 들어 있어 따로 바꿀 것이 없습니다(모든 요청을 `api/index.py` → Flask 앱으로 전달).
2. 프로젝트 **Storage** 탭 → **Neon (Postgres)** 생성 후 이 프로젝트에 연결 → `DATABASE_URL` 환경변수가 자동으로 들어갑니다.
3. **Deployments → 최근 배포 → Redeploy** (환경변수는 다시 배포해야 적용)
4. 이후 `main` 브랜치에 푸시하면 자동으로 다시 배포됩니다.

| 항목 | 내부망 서버 | Vercel |
|---|---|---|
| DB | SQLite 파일(`data\tasks.db`) | `DATABASE_URL`의 PostgreSQL. 표가 없으면 첫 요청 때 자동 생성 |
| DB 미연결 시 | — | 임시 저장소(`/tmp`)로 동작하며 화면에 빨간 경고. 데이터가 언제든 사라짐 |
| 초기화 전 자동 백업 | `backup\` 폴더에 파일 | 없음(Neon의 복원 기능 사용) |
| 한 번에 올릴 수 있는 파일 | 300MB | 약 4.5MB(Vercel 제한). 넘으면 나눠서 올리라는 안내 |
| 시간 | 서버 PC 시간 | 한국 시간(KST)으로 고정 |

## 3. 백업

`backup.bat`을 실행하면 `backup\tasks_날짜_시각.db`로 DB를 복사합니다(30일 지난 백업은 자동 삭제). 서버가 켜져 있어도 안전합니다.

매일 자동 백업(작업 스케줄러 등록, 예: 매일 18:30):

```bat
schtasks /create /tn "문서기한관리 백업" /tr "\"C:\경로\backup.bat\"" /sc daily /st 18:30
```

복원: 서버를 끄고 백업 파일을 `data\tasks.db`로 복사한 뒤 다시 실행합니다.

## 4. 사용법 요약

| 화면 | 내용 |
|---|---|
| 업무 목록 | 처음 접속 시 본인 이름 선택(브라우저에 기억). 오늘/주간/월간, 내 업무/부서 전체(담당자별). 빨강=기한 지남, 주황=D-3 이내, 회색=완료 |
| 업무 상세 | 유형·기한·담당자·메모 수정, 단계 추가/수정/삭제/순서 변경, 템플릿 적용, 완료 처리. 남의 업무는 읽기 전용(서버에서도 거부) |
| 접수문서 가져오기 | 엑셀 1개 + HWP 여러 개를 끌어다 놓기 → 열 매핑(최초 1회, 저장됨) → 미리보기에서 확인·수정 → 등록. 이미 등록된 문서번호는 건너뜀 |
| 설정 | 템플릿, 담당자 명단(추가·이름 변경·비활성화), 식별 키워드 확인, **데이터 초기화** |

### 데이터 초기화 (설정 화면 맨 아래)

등록된 업무를 한꺼번에 지웁니다. **부서 전원의 업무**가 지워지므로 주의하세요.

- 범위: "가져오기로 등록한 업무만"(기본) 또는 "직접 등록 업무까지 전체"
- 선택: 담당자 명단 비우기(남은 업무의 담당자는 유지), 저장된 엑셀 열 매핑 지우기
- 템플릿과 식별 키워드는 지워지지 않습니다.
- 확인 칸에 `초기화`를 입력해야 버튼이 켜집니다.
- 실행 직전 DB가 `backup\before_reset_날짜_시각.db`로 자동 백업됩니다. 되돌리려면 서버를 끄고 그 파일을 `data\tasks.db`로 복사한 뒤 다시 실행하세요.

- 지원 파일: 목록 `.xlsx .xls .csv`(온나라의 HTML형 .xls 포함), 본문 `.hwp`(HWP 5.0) `.hwpx .txt`
- 배포용/암호 HWP는 읽을 수 없어 "미매칭"에 표시됩니다. 엑셀 행과 직접 짝지은 뒤 유형·기한을 입력하세요.

### 온나라 접수문서 목록 엑셀

열 이름으로 자동 매핑합니다(처음 한 번 확인 후 저장). 시트가 여러 개면 목록으로 보이는 시트를 자동으로 고릅니다.

| 항목 | 엑셀 열 이름 예 | 쓰임 |
|---|---|---|
| 접수번호 | 접수번호 | 우리 부서 번호. **중복 등록 판단과 본문 짝짓기에 우선 사용** |
| 문서번호 | 문서번호 | 발신 기관 번호(본문 "시행" 칸). 기관이 달라도 겹칠 수 있어 접수번호가 없을 때만 중복 판단에 사용 |
| 제목 | 제목 | 필수. 본문이 없을 때 유형 추정에 사용 |
| 발신기관 / 발신부서 | 발신기관, 발신부서 | 합쳐서 "공군본부 정보화기획과"처럼 표시 |
| 생산일자 | 생산일자 | 발신부서가 문서를 생산한 날. 업무 목록·상세에 표시. 엑셀에 없으면 본문 "시행 ○○과-123 (날짜)"의 날짜 사용 |
| 접수일시 | 접수일시 | 기한 식별 기준일(연도 보정, 접수일 이전 날짜 제외) |
| 처리자 | 처리자 | 담당자. 명단에 없으면 자동 추가 |
| 결재상태 | 결재상태 | 접수 처리 상태(참고 표시만). **등록 여부와 관계없음** — 처리완료여도 회신·전파면 등록 대상 |

### 본문 짝짓기 순서

1. 본문 하단 "접수 ○○과-1234" ↔ 엑셀 접수번호
2. 본문 하단 "시행 ○○과-1234" ↔ 엑셀 문서번호(같은 번호가 여러 행이면 미매칭으로 보내 직접 고르게 함)
3. 본문·파일명 안에 엑셀 번호가 들어 있으면(예: `2026-09-08_정보화기획과-3592.hwpx`) 그 행

### 본문이 없는 문서

엑셀에만 있고 본문 파일이 없으면 **제목으로 유형만 추정**합니다("제목으로 추정" 표시, 기한은 비어 있음). 제목 키워드는 `rules_config.json`의 `title_reply_keywords`, `title_spread_keywords`입니다. 기한 미정 업무는 "오늘" 보기의 **기한 미정** 칸에 모입니다.

## 5. 자동 식별 규칙 고치기

`rules_config.json`의 키워드 목록을 고치고 저장하면 다음 가져오기부터 바로 적용됩니다(재시작 불필요).

- `reply_keywords`: 회신으로 볼 문구
- `spread_keywords`: 전파로 볼 문구
- `deadline_context_keywords`: 이 문구가 있는 문장의 날짜를 기한 후보로 우선
- `title_reply_keywords` / `title_spread_keywords`: 본문이 없을 때 제목으로 회신/전파를 추정할 단어
- `ignore_line_patterns`: 식별에서 뺄 줄(정규식). 기본값은 "1. 관련:" 줄

## 6. 시험용 샘플

- `samples\` : 온나라 형식 접수 목록 100건 엑셀과 본문 HWPX 1건. 가져오기 화면에 둘 다 끌어다 놓으면 됩니다.
- 추가 시험 파일(HWP 5.0, 문서번호 없음·배포용 사례 포함)이 필요하면:
  ```bat
  python tools\make_samples.py
  ```
  `samples_test\` 폴더에 만들어집니다.

## 7. 파일 구성

| 파일 | 설명 |
|---|---|
| `app.py` | 서버(Flask + waitress), API |
| `rules.py` / `rules_config.json` | 문서번호·유형·기한 식별 규칙 / 키워드 |
| `parsers.py` | 엑셀·HWP·HWPX 읽기 |
| `db.py` | 저장소: SQLite(`data\tasks.db`), `DATABASE_URL`이 있으면 PostgreSQL |
| `api\index.py`, `vercel.json`, `.vercelignore` | Vercel 배포 설정 |
| `static\` | 화면(HTML/JS/CSS) |
| `run.bat`, `backup.bat` | 실행, 백업 |

## 8. 알려진 한계

- 로그인이 없어 다른 사람 이름을 고르면 그 사람 업무를 고칠 수 있습니다(실수 방지 수준). 모든 수정에 최종 수정자·일시가 남습니다.
- 규칙 기반이라 오식별이 있을 수 있습니다. 미리보기의 근거 문장을 확인한 뒤 등록하세요.
- 알림 기능은 없습니다(색 강조와 "오늘" 보기로 대체).
